# ゴミ箱の市場調査データ（PBL1）

参照日：2026-10-21。室内用200件、屋外用184件、合計384件の事例を収録しました。目標は各200件程度です。屋外用は、確認・重複統合後の実収録数を記載し、件数を合わせるための架空製品や色違いの水増しはしていません。

## ファイル

- `indoor_market.xlsx` / `outdoor_market.xlsx`：同じ58項目。Summary（読み方・集計）、Products（製品表）、Fields（項目辞書）、Missing（欠損理由）、Groups（統合記録）の5シート。
- `indoor_products.csv` / `outdoor_products.csv`：Excelと同じ列・同じ値。UTF-8 BOM付き、1行1事例、ヘッダーは英語の固定名。
- `schema.json` / `field_dictionary.csv`：日本語の項目名、型、単位、定義。
- `missing_reasons.csv`：製品ID×項目の欠損理由。環境別のファイルもあります。
- `grouping_audit.csv`：代表行に統合した確認記録と出典。
- `coverage.csv` / `summary_counts.csv`：確認率と基本集計。
- `screening_exclusions.csv`：部品単品、集積保管用途、取扱終了等として除外した記録。検索で見つかった候補全体の完全な一覧ではありません。
- `analyze_market.py`：pandasでの読み込み・集計、matplotlibによるグラフ出力。

## 収集・統合の方針

正式なメーカー、ブランド、法人小売店・通販の新品商品情報を対象にしました。主な採用出典はモノタロウ、ニトリ、楽天市場、専門通販、メーカー公式通販等です。Amazonも探索に利用しましたが、出品者・代表仕様まで十分確認できない掲載は採用していません。個人・中古出品は不採用です。実物を取り寄せた真正性確認や測定は行っていません。

同一メーカー・シリーズ内で、確認できた幅/高さ・奥行/高さが基準仕様からそれぞれ10%以内であれば、概ね同じ比率として容量・色違いを統合しました。同一投入面の穴数や開口形状、フタ機構が違う場合は区別しています。寸法不足の記録は同シリーズ内で暫定統合し、`grouping_status`に明示しました。別シリーズが同じ比率という理由だけでは統合していません。材質やOEMの同一性を推測しての統合もしていません。

家庭・オフィス用は、取得できた同じグループの仕様から15〜20Lを優先し、該当がなければ17.5Lに近い確認容量を選びました。容量不明も残しています。室内200件のうち15〜20Lは55件です。全市場の全容量を網羅した結果ではありません。屋内外兼用は屋外ファイル側に1回収録しました。

屋外用には公園・店舗・公共施設・キャンプ向けを含みます。`use_category`で利用場面を分けられます。袋をまとめて保管する集積庫・ゴミステーション、フタや部品だけの販売は比較対象から除外しました。本体単品は実在するゴミ箱として収録し、確認できる場合はフタ別売の条件を保持しました。

## 欠損と確認方法

数値の空欄は欠損です。0に置換していません。`lid_present=0`だけは「フタなし」という実値です。

| reason_code | 意味 |
|---|---|
| not_confirmed | 参照資料から代表仕様の値を確認できなかった |
| not_applicable | その形状・記録に対する項目ではない |
| conflict | 不一致、0値・異常値等があり数値化を保留した |

`not_confirmed`は「メーカーが非公表」と断定するコードではありません。画像内や別資料に情報が存在する可能性もあります。

本体形状と開口形状、本体寸法と開口寸法、容器容量と対応袋容量は区別しました。写真の縮尺や本体外寸から開口寸法を推定していません。角形・円形等を写真で観察できたものは`opening_shape_basis=product_photo_observation`とし、掲載文による確認と区別しました。写真での角形分類は角丸半径や厳密な幾何形状の測定を意味しません。閉じたフタだけの写真から穴形状を推定していません。

開口形状を確認できたのは室内29/200件、屋外36/184件。開口寸法5列のどれかを確認できたのは室内10件、屋外20件です。欠損を除いて作図する場合も、確認件数と総件数を併記してください。形状比較の精度を高める次段階では、候補を絞ってメーカー図面の追加確認や実測を行うと有効です。

販売店とメーカーで仕様が異なる場合は、メーカーで確認できた値を優先し、出典と訂正を記録しました。解消できない容量の不一致や寸法の異常値は欠損にしています。NTO等の角形開口の2辺は、側面穴の縦寸法と奥行の混同を避けるため長辺・短辺で保持した場合があります。

## 解釈の範囲

これは目的に沿って集めた製品事例の便宜的標本です。サイト・メーカーの偏りがあり、販売数量、市場シェア、売れ筋順位、消費者全体の評価を表すデータではありません。室内外の構成比を、そのまま市場全体の構成比として扱わないでください。

価格は代表仕様について取得できた公開の税込表示で、送料を除きます。複数個セットの価格は販売単位を併読してください。実際の決済価格や現在庫を一括検証したものではありません。品切れ表示の製品は実在・販売掲載の事例として扱い、その条件を記録しました。

`review_summary`は実在する公開投稿を読めた場合のみ要約しています。投稿者の個別購入の真正性は独立検証していません。未確認を「レビューなし」とは解釈しないでください。`throwing_assessment`は調査者による未検証の考察です。投擲成功率・跳ね返り・散乱防止効果を実証する数値は収録していません。

## Pythonで使う

```bash
pip install -r requirements.txt
python analyze_market.py
python analyze_market.py --plot
```

最初の実行は集計CSVを、`--plot`付きでは開口形状・フタ方式・容量区間・確認率のPNG/SVGを出力します。未確認を明示した作図です。初期の集計結果は`analysis_output/`に同梱しています。

```python
from pathlib import Path
from analyze_market import load_products

df = load_products(Path('.'))
print(df.groupby('environment')['opening_shape'].value_counts(dropna=False))
known = df[df['opening_dimension_status'].eq('confirmed')]
```

この作成環境ではpandasの読み込み・集計とPython構文検証を実行しました。matplotlibは未導入のため、`--plot`の画像生成はこの環境では未実行です。
